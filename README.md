# Python 101

A personal learning project for studying and practicing Python fundamentals.

The examples in this repository are intentionally simple and include comments that explain what
the code does. The project will grow as I learn new Python concepts and add more exercises.

## Current Topics

The `hello_python.py` file currently covers:

- Strings and substrings
- String concatenation and formatted strings
- Common string methods
- Escape sequences
- Membership operators (`in` and `not in`)
- Basic arithmetic operators
- Built-in numeric functions
- The `math` module

## Project Structure

```text
Python 101/
├── app.py
├── hello_python.py
└── README.md
```

- `hello_python.py`: Main learning file with documented examples.
- `app.py`: Small collection of introductory string examples.
- `README.md`: Project overview and learning progress.

## Requirements

- Python 3

No third-party packages are required.

## Running the Examples

Clone the repository and move into the project directory:

```bash
git clone <repository-url>
cd "Python 101"
```

Run the main learning file:

```bash
python3 hello_python.py
```

You can also run the smaller introductory example:

```bash
python3 app.py
```
